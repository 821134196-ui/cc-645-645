# 企业培训录播授权与到期下架系统

员工能否观看课程，取决于**所在部门 × 讲师对具体视频版本的授权期限**。管理员负责许可登记、续签与下架；授权一旦到期或下架，员工此前拿到的播放/下载地址立即失效。

## 技术栈

- 后端：TypeScript + NestJS 10
- 前端：React 18 + Vite
- 数据库：Prisma 5 + SQLite
- 视频：本地文件存储（`backend/storage/videos`），HTTP Range 流式播放
- 提醒：模拟实现（不发真实邮件，提醒内容落库可回查）

## 一条本地命令启动

```bash
./start.sh
```

脚本会自动完成：安装依赖 → 生成 Prisma Client → 建库与种子 → 构建前后端 → 启动服务。
启动后访问 **http://localhost:3000**（后端同时托管前端打包产物）。

> 首次种子会尝试下载公开 MP4 样本；无外网时自动生成占位文件，鉴权与流式逻辑不受影响。

其他常用命令：

```bash
npm run seed -w backend       # 重置演示数据
npm run test:e2e -w backend   # 端到端验证（40 项断言，使用独立 test.db）
npm run dev -w frontend       # 前端开发模式（5173，自动代理到 3000）
npm run start:dev -w backend  # 后端 watch 模式
```

## 核心设计

### 授权判定（三重条件，服务端每次请求实时检查）

1. 许可状态为 `ACTIVE`（未下架、未被续签替代）；
2. 当前时间在 `[validFrom, validUntil]` 区间内；
3. 许可的可观看部门包含员工所在部门。

### 播放/下载地址防旧链接

- 员工点“播放/下载”时先调 `POST /api/media/issue`，服务端鉴权后签发 **HMAC 签名、10 分钟有效**的地址；
- 真正取流的 `/api/stream`、`/api/download` **不只验签名，还会再查一次库**——
  许可到期、被下架、员工调岗换部门后，旧地址立即 403；
- 视频文件不通过静态目录暴露，跨部门员工无法猜测路径直接访问；
- 所有放行与拒绝都写入 `AccessLog`（含拒绝原因，如 `LICENSE_EXPIRED`、`DEPARTMENT_NOT_LICENSED`、`INVALID_OR_EXPIRED_URL`、`NO_ACTIVE_LICENSE:REVOKED`）。

### 续签必须是新记录，不允许延长旧许可

- `POST /api/admin/licenses/renew`：必须指定视频版本并上传新许可文件；
- 事务内将该版本所有 `ACTIVE` 许可置为 `SUPERSEDED`，再插入一条全新 `ACTIVE` 记录；
- 旧许可的部门、期限、许可文件、创建时间原样保留，可在“课程与版本 → 授权历史”中逐代回查。

### 下架保留原因与历史

- 下架必须填写原因，许可置为 `REVOKED` 且 `revokeReason` 落库；
- 不删除任何许可/日志数据，员工端列表显示“已下架”，旧链接立即失效。

### 管理端功能

- **未来一周续签**：列出 7 天内到期及已过期未处理的许可，一键续签；
- **许可管理**：按状态（生效中 / 已续签替代 / 已下架）筛选，登记、续签、下架；
- **课程与版本**：查看每个视频版本的完整授权历史与许可文件；
- **访问记录**：按版本、放行/拒绝筛选，追踪越权与到期访问；
- **模拟提醒**：手动扫描临期许可，模拟邮件落库（同一许可每天最多一条）。

## 端到端验证覆盖（`npm run test:e2e -w backend`）

1. 员工课程列表显示状态/到期时间/剩余天数，未授权部门不可见；
2. 合法播放：签发地址 + Range 206 流式；
3. 跨部门越权播放/下载被拒；
4. 篡改 URL 用户参数、伪造签名被拒；
5. **先合法拿到地址，许可到期后同一地址立即失效**，重新打开同样被拒；
6. **版本续签产生新记录，旧许可截止日期不变且置 SUPERSEDED**；
7. **下架必须填原因，下架后旧链接立即失效，历史与原因保留**；
8. 续签清单与状态筛选正确；
9. 各类放行/拒绝访问记录均可回查；
10. 模拟提醒生成与去重。

结果：**40 项断言全部通过**。

## 目录结构

```

  src/auth/                # 三重鉴权、HMAC 签名、Range 流式
  src/admin/               # 许可登记/续签/下架、续签清单、历史、访问记录
  src/reminder/            # 模拟提醒扫描
  scripts/e2e.ts           # 端到端验证
  storage/videos/          # 本地视频文件
  storage/licenses/        # 许可文件
frontend/src/
  employee/                # 员工端：课程列表 + 播放器
  admin/                   # 管理端五个标签页
```
